Release & Upgrade Info (v1.6.6 Out Now)

Users on v1.6.5 (and v1.6.4) can install v1.6.6 directly as a seamless in-place update. If upgrading from an old debug build (com.tarumi.reader.debug), follow these steps to preserve your reading data:

  1. Create a data backup: Go to Settings → Backup & restore → Create data backup and save it.
  2. Uninstall your old app-debug version.
  3. Install the latest app-release.apk (Package ID: com.tarumi.reader).
  4. Restore progress: Open the app, go to Settings → Backup & restore → Restore and pick your saved backup.
