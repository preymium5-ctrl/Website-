Migration Notice (Upgrading to v1.6.2+)

Starting with **v1.6.2**, Tarumi switches from debug to a minified production APK (Package ID: com.tarumi.reader). You must reinstall the app following these steps to preserve your reading history:

  1. Create a data backup: Go to Settings → Backup & restore → Create data backup and save it.
  2. Uninstall your existing Tarumi / app-debug version.
  3. Install the new app-release.apk downloaded above.
  4. Restore progress: Open the app, go to Settings → Backup & restore → Restore and pick the saved backup.
